# Changelog

All notable changes to Parnian Pay for WooCommerce are documented here.

## [1.1.0] - 2026-10-02

### Added
- Store-currency invoices: the PARC amount is calculated by the gateway from your dashboard rate.
- Support for IRHT / IRHR (thousand toman / thousand rial) currencies.

### Changed
- Payment method is hidden when the gateway is inactive or the store currency has no rate.

## [1.0.0]

- Initial release.
